## Notes for LLMs

- Always specify bundle (Adafruit or Community) when recommending a library.
- Import name = filename in `CIRCUITPY/lib/` without `.mpy`. Not always derivable from repo name.
- Do **not** conflate with MicroPython modules — different ecosystems, different APIs.
- Bundle version must match CircuitPython firmware version or `ImportError` results.
- Multi-file libraries are directories; copy the whole folder, not just `__init__.mpy`.
- `adafruit_bus_device` and `adafruit_register` are required by the vast majority of drivers.
- `circup` handles both bundles and is the canonical install tool.
- Adafruit examples links are confirmed; Community ones are confirmed only where marked.
